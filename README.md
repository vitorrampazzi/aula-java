# Java Coursework

A study archive of Java class exercises, organized by lesson. The examples cover console input, arithmetic, conditions, loops, and introductory object-oriented programming.

## Contents

| Directory | Focus |
| --- | --- |
| `java/aula 1302/` | Starter Java project, console output, input, and arithmetic |
| `java/aula 2402/` | Individual programming exercises |
| `java/aula 1003/` | Console exercises with input validation and loops |
| `java/aula2403/` | Client class and program exercises |
| `java/aula3103/` | Client objects and methods |
| `java/aula0704/` | Menu and client exercises |
| `java/exercicios/` | Draft inventory management exercises |
| `java/testes/` | Additional practice files |

The original Portuguese folder and class names are preserved. `Dynamic/` also contains an empty Python lesson file.

## Explore locally

Install a Java Development Kit (JDK), then clone the repository:

```bash
git clone https://github.com/vitorrampazzi/aula-java.git
cd aula-java
```

Open an individual lesson in a Java IDE or Visual Studio Code with Java support.

### Starter example

The simple `App.java` example prints `Hello, World!`. From the repository root:

```bash
cd "java/aula 1302/src"
javac App.java
java App
```

## Project scope

The folders are separate learning exercises rather than one application. Some files are incomplete drafts, including the inventory exercises, and may require corrections before compilation. There is no shared Maven or Gradle build.
